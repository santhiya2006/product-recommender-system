
# 🛍️ Product Recommender System

A Flask-based Product Recommender System that recommends similar products based on category using MongoDB Atlas.

## 📌 Project Overview

This project allows users to search for products and receive recommendations for related products. It is built using Flask, MongoDB Atlas, HTML, CSS, and Bootstrap.

---

## ✨ Features

- 🔐 User Login & Registration
- 👨‍💼 Admin Dashboard
- ➕ Add New Products
- 🔍 Search Products
- 🤖 Product Recommendations
- 🖼️ Product Images
- ☁️ MongoDB Atlas Integration
- 🚩 Feature Flag Support

---

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/santhiya2006/product-recommender-system.git
```

### Go to project folder

```bash
cd product-recommender-system
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Create a `.env` file

```env
MONGO_URI=YOUR_MONGODB_URI
SECRET_KEY=YOUR_SECRET_KEY
```

### Run the application

```bash
python app.py
```
